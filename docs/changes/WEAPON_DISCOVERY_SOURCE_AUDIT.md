# Weapon Discovery v1 source audit

The initial worktree was clean on `master` at `ffd1662777ad0cb2800393a9e7a3323914425624`. Recent commits were `ffd1662` (blood spill), `4e461d3` (feeding movement), `8fdce73` (tree fire), `96fa53f` (Arch-vile FX), and `720d55d` (Inferno ash). Cached `origin/master` was 0 ahead and 0 behind. GitHub port 443 was unreachable, so live remote parity could not be verified.

- `linuxdoom-1.10/p_inter.c` owns `P_KillMobj`, `P_TouchSpecialThing`, `P_GiveAmmo` and `P_GiveWeapon`. The death switch spawns a clip for Zombiemen and SS, a shotgun for Shotgun Guys, and a chaingun for Chaingunners. This was the sole world weapon-drop site found. `P_DropWeapon` lowers the dead player's weapon sprite.
- `p_mobj.c` zeroes new actors in `P_SpawnMobj`. Map spawns set their THINGS record. `P_RemoveMobj` excludes `MF_DROPPED` items from the item respawn queue. `p_enemy.c` covers corpse handling, resurrection, Arch-vile damage and barrel splash. Weakpoint, acid and elemental damage reach the shared death path. Arcade scoring and existing death hooks run before the switch.
- `info.c` and `info.h` define the pickup actors and sprites. `doomdef.h` defines ammo categories and skills, and `d_items.c` maps weapons to ammo. Vanilla loads are 10 bullets or 4 shells. A dropped clip uses half a load, a shell pickup uses one load, and a dropped weapon grants one load. Trainer and Nightmare double ammo.
- `d_deh.c` supports ammo load sizes and remapping actor definitions and states. No custom enemy weapon-drop table was found in the audited code. The strict modes target the two classic weapon-dropping actor types. Replacement art still comes from the current WAD. Ordinary DeHackEd ammo pickups keep their configured loads.
- `p_saveg.c` archives native `mobj_t` records. `scene3d.h` owns the F4 draft and stored setting, `settings_panel.cpp` owns menu options and config serialization, `scene3d/config.cpp` reads and writes `graphics.cfg`, and `scene.cpp` applies the setting to the Doom core independently of the accelerated renderer.
